Карточка заявки v4 · плоские строки

Рельса 680px, ноль подложек, всё на 1px-разделителях. Порядок: шапка → вопрос клиента → детали заявки (тип, ответственный, тихий inline-edit параметров) → вложения → разбор (таблица всегда, даже для одного объекта) → телеметрия выбранного объекта → оценка разбора → комментарии → связанные заявки → передать монтажникам. Ответ живёт в липком баре снизу: щёлкните поле «Ответить клиенту…» — оно раскроется, появятся шаблон, публичный/приватный и чип «черновик ИИ» для выбранного объекта. Копирование для монтажника переехало из бара в секцию «Передать монтажникам»: два формата — календарь и мессенджер — и текст появляется только по кнопке. Активная секция помечена лаймовой полосой слева. Клик по строке таблицы выбирает объект и обновляет телеметрию; иконка ▤ в строке открывает и закрывает трек-панель. Если тип заявки «Не указан», «Детали заявки» раскрываются сами — чинить нужно там. В баре работают «Шаблон ▾» (поиск, категории, плейсхолдеры, предпросмотр) и «Ещё ▾» → модалка смены статуса. У вложений виден прогресс OCR. У всех кнопок есть подсказки — наведите. Разбор разделён по стоимости: факты и предварительный вердикт считаются правилами бесплатно при открытии заявки, DeepSeek зовётся отдельно кнопкой «Ответ ИИ» в телеметрии. Источник вердикта виден по пилюле: пунктир — правила, сплошная в цвет вердикта с ✦ — ИИ, нейтральная с ✎ — ручная правка оператора. Переключатель «вердикт» показывает оба состояния.

Заметки для реализации. 1) Все 8 колонок разбора влезают в 648px без скролла за счёт коротких заголовков — полные подписи («ГЛОНАСС заявл.», «По факту») ушли в тултипы. 2) Статус «В работе» приходит цветом #2B6684 — текст им нечитаем, поэтому обводка цветом статуса, а текст осветлён до #7EC8E3; правило «цвет статуса → осветлённый текст» нужно заложить в src/lib/status.ts. 3) Блок «Почему такой вердикт» — это существующий reasoning из TelemetryPanel.tsx, которому раньше не хватало подписи. 4) Гард «Сначала укажите тип заявки» завязан на тип: выберите в «Деталях» тип «Не указан» — предупреждение появится в баре, «Ответить и решить» и «Подтвердить» в модалке заблокируются (Okdesk отклоняет смену статуса при type_code = inner). 5) Статус «В работе» Okdesk открывает только для типов departure / departure_fuel — в меню «Ещё» это написано подписью пункта. 6) Плейсхолдеры шаблонов — русские [квадратные скобки], [сегодня]/[вчера]/[завтра] считаются автоматически по МСК и в форме заблокированы, остальные предзаполняются из разбора выбранного объекта. 7) Пустые «Местоположение техники» / «Контактное лицо» / «Номер телефона» блокируют перевод в «В работе» (баг 64197) — поэтому пустой параметр подсвечен предупреждающим плейсхолдером. 8) Источник вердикта — поле verdict_source: rules (пунктирная пилюля, хвост «по правилам») / ai (сплошная обводка в цвет вердикта, глиф ✦ и полоса доверия из confidence) / operator (нейтральная обводка и глиф ✎, ручная правка сильнее машины). Заливку не трогаем — она занята статусами Okdesk. heuristic_category остаётся в модели после прогона: если он разошёлся с verdict, под таблицей и в телеметрии печатается «правила: X → ИИ: Y». 9) reasoning, confidence и draft_answer приходят только от DeepSeek, поэтому до нажатия «Ответ ИИ» этих блоков нет физически — на их месте кнопка с честной ценой вызова. Кнопка одна на заявку: модель разбирает все объекты за один вызов.
